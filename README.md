# tarangam.github.io
Interactive RF Antenna Synthesis &amp; Design Tool

TARANGAM (தரங்கம் )Interactive RF Antenna Synthesis, Mechanical Blueprint & Cut-Sheet WorkbenchEtymology: Tarangam (தரங்கம் in Tamil · तरङ्गम् in Sanskrit) means wave or oscillation. TARANGAM is a zero-dependency, browser-native RF CAD and mechanical cut-sheet engine built for embedded hardware engineers, amateur radio operators, robotics teams, and RF students. Given a target center frequency and physical material constraints, it synthesizes exact fabrication dimensions across seven core antenna topologies and maps every calculated figure directly onto an interactive, bidirectional 2D technical drawing.The Problem It SolvesBuilding and tuning physical antennas for IoT telemetry (433 MHz / 866 MHz / 915 MHz LoRa), 2.45 GHz Wi-Fi/BLE microcontrollers, GNSS receivers, or VHF/UHF links usually forces builders into one of two broken workflows:Blind Number Dumps from Legacy Web Calculators: Conventional web calculators output unlabelled text lists (L1 = 164.2 mm, L_C = 21.0 mm, y0 = 18.4 mm) without showing where those measurements sit physically. Builders are left guessing whether a dimension is measured tip-to-tip, center-to-center, from the outer shield or inner conductor, or inside a recessed PCB notch.Heavy Desktop FEM/MoM Overkill for Bench Prototyping: Launching full-wave electromagnetic solvers (Ansys HFSS, CST Studio, or NEC2) just to cut a brass rod dipole, bend a copper J-Pole, or size an FR-4 microstrip patch introduces hours of setup and licensing friction.Ignored Physical Realities (Velocity Factor, End-Capacitance & Fringing): Simple $\lambda / 2$ or $\lambda / 4$ rules-of-thumb ignore conductor velocity factor ($VF$), rod diameter slenderness ($L/d$ capacitive end-loading), ground-plane radial droop angle ($\theta$), and dielectric fringing fields ($\Delta L$), producing antennas whose resonant VSWR dip misses the target band by 30–80 MHz.TARANGAMbridges the gap between textbook electromagnetics and the hardware workbench: every mathematical output is visually bound to a live, dimensioned CAD schematic so you see what is what before you cut wire, drill a boom, or etch copper.Core Capabilities & Supported TopologiesThe engine synthesizes seven distinct antenna architectures with real-time unit conversion Mathematical & EM Synthesis ReferenceAll dimensions are derived from first-principles electromagnetic synthesis equations:Free-Space Wavelength:
$$\lambda_0 = \frac{c}{f_0}, \quad c = 299,792,458\text{ m/s}$$Slenderness & Velocity Factor Effective Shortening ($k_{\text{eff}}$):
$$k_{\text{end}} = 1 - \frac{0.045}{\log_{10}(L / d)}, \quad k_{\text{eff}} = \min\left(VF,\; VF \cdot (0.985 + 0.015\,k_{\text{end}})\right)$$Microstrip Patch Hammerstad-Jensen Fringing Model (CAD-04):
$$W = \frac{c}{2f_0}\sqrt{\frac{2}{\varepsilon_r + 1}}, \quad \varepsilon_{\text{reff}} = \frac{\varepsilon_r + 1}{2} + \frac{\varepsilon_r - 1}{2}\left(1 + 12\frac{h}{W}\right)^{-1/2}$$$$\Delta L = 0.412\,h\,\frac{(\varepsilon_{\text{reff}} + 0.3)\left(\frac{W}{h} + 0.264\right)}{(\varepsilon_{\text{reff}} - 0.258)\left(\frac{W}{h} + 0.8\right)}, \quad L = \frac{\lambda_0}{2\sqrt{\varepsilon_{\text{reff}}}} - 2\Delta L$$ContributingContributions from the RF, amateur radio, and embedded hardware communities are welcome!
